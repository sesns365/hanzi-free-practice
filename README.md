# 生字自由練習

從「生字書寫練習網」獨立出來的自由練習工具：選教材版本與課次，或自行選字，進行部件、筆順引導與自由書寫練習。不需登入，練習紀錄只存在使用者自己的裝置。

「逐字設定」可以逐字修改教材與讀音（語詞、注音、例句、解釋、教學提醒、報讀文字）以及部件分組與部首答案；設定存在該裝置的瀏覽器（localStorage），同一台載具之後開啟都會套用。

## 部署到 GitHub Pages

1. 把這個資料夾的所有內容上傳到 GitHub 儲存庫的 `main` 分支。
2. 到儲存庫的 Settings → Pages，Source 選「GitHub Actions」。
3. 之後每次推送到 `main` 都會自動建置並發布。

## 本機預覽

```
npm install
npm run dev
```
