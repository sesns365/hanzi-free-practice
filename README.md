# 自由練字板

從「生字書寫練習網」獨立出來的自由練習工具：選教材版本與課次，或自行選字，進行部件、筆順引導與自由書寫練習。不需登入，練習紀錄只存在使用者自己的裝置。

## 學生端

- 記住這台裝置上次的版本、課次與練習方式；多字練習沒練完，下次可以接著練。
- 自由書寫換到下一個字時自動保存字跡並得星。
- 「簡易畫面」只留下必要按鈕；語詞顯示注音。
- 老師設定班級人數後，學生先點座號，紀錄與進度各自分開（只用座號，不存姓名）。
- 支援離線：開過的頁面、字型與筆順資料會存在裝置裡。

## 老師專區

頁尾的「老師專區」進入（可設定數字密碼，避免學生誤入；網址加 `?teacher=1` 也可以）。

- 練習預設：練習步驟、書寫方式、字形提示、簡易畫面、是否鎖定、預設版本課次、班級人數、老師密碼。
- 逐字教材與讀音、逐字部件與部首答案。
- 自訂字單：課本以外的字。
- 派課連結與 QR Code。
- 設定檔與共用：匯出 `class-settings.json`，放到儲存庫的 `public/class-settings.json`，所有載具下次開啟會自動換成這份設定。

### 派課連結的網址參數

| 參數 | 說明 |
| --- | --- |
| `book` | 教材版本代號，例如 `nanyi-5a`、`kangxuan-2a`、`hanlin-3a` |
| `lesson` | 課次代號，或直接寫第幾課的數字；`all` 表示整冊 |
| `start=1` | 打開後直接開始整課練習 |
| `chars` | 直接指定要練的字，例如 `chars=山水火` |
| `steps` | `writing`（直接書寫）或 `parts`（畫部件、組部件、書寫） |
| `mode` | `free`（自由書寫）或 `guided`（筆順引導） |
| `hint` | `none`、`pale`、`partial` |
| `lock=1` | 學生不能更改練習方式 |
| `simple=1` | 使用簡易畫面 |

## 部署到 GitHub Pages

1. 把這個資料夾的所有內容推送到 GitHub 儲存庫的 `main` 分支。
2. 到儲存庫的 Settings → Pages，Source 選「GitHub Actions」。
3. 之後每次推送到 `main` 都會自動建置並發布。

更新 `public/strokes` 或字型後，請把 `public/sw.js` 裡的 `VERSION` 改成新的值，載具上的舊快取才會清掉。

## 回歸測試

`tests/` 內有兩支 Playwright 腳本（需先 `npm run build`，並把 `dist` 放到本機伺服器的 `/free-practice/` 路徑）。每次修改後三種練習模式（自己寫、跟著筆順寫、先畫部件）都要跑過再推送。
